# After Hours: Assignment 6

A standalone jQuery investigation page based on the guest illustration in `Assignment 6.pdf`.

## Run locally

Open `index.html` in a modern browser with an internet connection. jQuery 3.7.1 and Open Peeps avatars are loaded from their public CDNs.

## Features

- Four rooms on two floors with all 21 guests and their clothing, arrival times, AITU status, and belongings.
- Twenty case buttons that search the rendered guest cards with jQuery selectors and traversal.
- Spotlight, one-time guest jumps, dynamic Miras/Natasha cases, guest detail cards, animated room moves, and time sorting with order restoration.
- Responsive layout and keyboard support for guest cards and modal dismissal.

## Files

- `index.html` - page structure.
- `styles.css` - visual design and responsive layout.
- `app.js` - party data, DOM rendering, cases, and jQuery effects.
- `Assignment6_YourName.docx` - report (fill in name, group, and repository URL).

## GitHub

Initialize or connect a GitHub repository and add its URL to the report before submission.
